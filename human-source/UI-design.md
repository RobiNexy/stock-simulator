# K 线模拟器（浅色）设计语言与配色规范

## 一、构成骨架：信息密度与视觉权重分配

**L1｜外松内紧。** 分区容器之间用留白和圆角把密集信息隔开，但容器内部保持行情软件级别的高密度；可爱感放在“区块之间”，不放在“数字之间”。
→ 对应该对象：左侧自选（240px）、中部图表（flex）、右侧盘口（280px）是三张独立卡片，卡片间距 12px、卡片圆角 14px；但卡内列表行高维持 32–36px，行内不做额外内边距膨胀。

**L2｜主图面积不可让渡。** 装饰性的留白和卡片不能以压缩图表为代价。
→ 约束：K 线画布面积 ≥ 视口 55%，右侧栏 ≤ 22%；宽度 <1440 时右侧盘口折叠为 tab，而不是压缩主图。

**L3｜权重靠字号阶梯与色彩范围来拉开，不靠加粗堆叠。**
→ 现价字号 ≈ 坐标轴标签字号 ×3；涨跌幅用胶囊承载（面积小、色块强）；标签（“现价”“成交量”）字号比其数值小 2–3 级，明度降一档。全站字重只用 400 和 600 两档；中间字重会让密集表格显得糊。

**L4｜颜色预算三段划分。** 全站颜色分成三个互不侵占的池子：结构色（负责层次）、语义色（锁定涨跌）、装饰色（配额使用）。任何装饰色进入数据区都算违规。
→ 这是本设计最核心的可迁移规则：可爱配色在金融界面里的可用面积很小，所以可爱感必须从形状、描边、留白和瞬时反馈里长出来，不能从主色相里长出来。

## 二、节奏与层级

**L5｜三级文字 + 四级数字，不设第五级。**
文字：主（标题、标的名称）→ 次（说明、单位说明）→ 弱（轴标签、时间戳）。数字：现价 → 涨跌额、涨跌幅 → 列表数值 → 轴刻度。

**L6｜节奏单位取 4 的倍数**：卡片内边距 16/12，卡片间距 12，胶囊内边距 10×4，行高 32/36。密度变化只通过改变行高实现，不通过改变字号。

**L7｜图表区自成一套节奏，与 UI 节奏分离。** 画布内：零圆角、零内边距、零阴影、零卡片；柱宽 4–7px、间距 1–2px，圆角取 0（任何圆角都会让短柱与十字光标变形）。UI 的圆角和图表没有圆角，是同一套设计语言里的两个气候带。

## 三、色彩配置

色值只是参考实例，可整体替换；不可替换的是“角色 + 关系约束”这一列。所有值均为浅色模式，无暗色变体。

### 3.1 结构色（只负责层次）

| 角色 | 参考值 | 约束 |
|---|---|---|
| 桌面底 | `#F7F3EC` | 暖奶油，不用纯白；纯白长时间盯盘刺眼，且与卡片无法再拉开层次 |
| 卡片面 | `#FFFFFF` | 卡片比桌面更亮，形成“纸放桌面”的正向层次 |
| 凹陷底（画布、输入框） | `#FDFBF7` | 低于桌面半档，用于可输入、可滚动区域 |
| 分割线 | `#EDE6DB` | 1px，仅用于表格行间 |
| 卡片与胶囊描边 | `#E6DCCD` | 暖灰，禁止冷灰（会与薄荷绿的跌色串味） |
| 网格线 | `#F0EAE1` | 虚线或点线；十字光标以外的网格永不实线 |
| 文字-主 | `#2C2723` | 暖黑，不用 `#000` |
| 文字-次 | `#6F665E` | 对白底对比 ≥ 4.5:1 |
| 文字-弱（轴、单位） | `#A1988E` | 只用于非关键信息，禁止承载数值 |
| 禁用 | `#C9C1B7` | |

### 3.2 语义色（锁定涨跌，禁止挪用为装饰）

| 角色 | 文字档 | 填充档 | 浅底档 |
|---|---|---|---|
| 涨 | `#E0455F` | `#FF7C8C` | `#FFECEF` |
| 跌 | `#17977A` | `#4FCFA8` | `#E8F8F3` |
| 平、不变 | `#8E959B` | `#D8D8D8` | — |

硬约束：

- **文字档与填充档必须分成两档。** 填充档可以更糖果、更亮（K 线实体、成交量柱、进度条）；文字档必须压暗到对白底 ≥ 4.5:1（表格数字、涨跌幅文本）。一档到底的结果是数字看不清，或者 K 线显得脏。
- **涨跌两色等明度。** 两色 L\* 差 ≤ 5、C\* 差 ≤ 10，否则盘面会整体“偏红”或“偏绿”，破坏中性观感。
- **红已被“涨”占用，所以危险、错误、删除禁用红色。** 一律改为琥珀色 `#C98A2E` + 图标，或紫色主色。这条比色值本身更重要。
- **成交量柱用涨跌填充档 30% 透明度**，不新增颜色。

### 3.3 装饰色（配额制，禁止进入主图与盘口）

| 角色 | 参考值 | 允许出现的位置 |
|---|---|---|
| 主交互（按钮、选中、Tab 下划线） | `#7A5CD6`，hover `#6847C4`，浅底 `#F1ECFD` | 全站 UI 控件 |
| 焦点环 | `#B9A6FF` @40% | 仅键盘可达控件 |
| 信息、链接 | `#4C9FD6` | 说明文字、帮助入口 |
| 提示、成就、新手引导 | `#FFC94D`，浅底 `#FFF6DC` | 瞬时反馈、空状态、结算页 |
| 警示（非涨跌） | `#C98A2E` | 风控提示、下单确认 |

选紫色的理由与审美无关：它落在红绿语义轴之外，且对红绿色弱用户仍可区分。

### 3.4 指标线色（主图内的第四类）

均线、MACD 等指标线只能用“低饱和结构色”：`#8E7CD8`、`#5FA8C9`、`#B98AC9`、`#8C8C8C`，线宽 1.5px，图例固定带序号 ①②③④。**主图区不得出现明度高、饱和度高的红、橙、绿系线条**——它们会被读成涨跌信号。四档颜色以线型（实线、长虚线、点线）为第二通道。

## 四、形式签名

**S1｜描边优先于阴影。** 阴影在奶油底上会显脏、发黄。层次只靠 1px 暖灰描边 + 底色明度差；卡片阴影最多 `0 1px 2px rgba(60,45,30,.04)`，且不得叠加。

**S2｜四级圆角。** 容器 14 → 控件 8–10 → 数据单元 4 → 图表画布 0。胶囊一律全圆。圆角值跨级不混用，是这套语言最容易识别的特征。

**S3｜涨跌双通道编码。** 色相 + 实心与空心：阳线空心描边（填充档色，无填充），阴线实心。色弱、红绿色盲、投影失真、截图转黑白时仍可读；也承接了 A 股行情软件的传统语感。

**S4｜可爱配额制。** 装饰色块、插画、圆润图形、动效只允许出现在 A 区：自选空状态、下单成功、模拟结算、新手引导、错误页、加载态、成就与连续盈利提示。B 区（K 线画布、五档盘口、成交明细、持仓数字）零装饰、零动效、零插画。

**S5｜模拟身份常驻。** 顶栏与下单按钮旁固定黄色胶囊“模拟盘”，面积不小于 56×20，不可被折叠或滚动隐藏。这是产品必需项，不是装饰。

**S6｜数字不参与可爱化。** 圆润字体只用于中文界面文案与标题；所有数字用等宽在册（tabular figures）的常规无衬线，禁止用圆体数字——圆体数字宽度不齐，密集表格列会错位。

## 五、排版参数

| 项 | 规格 |
|---|---|
| 中文 UI 字体 | 苹方、思源黑体，标题可用圆润黑体 |
| 数字字体 | 等宽在册，行内不换字族 |
| 字号阶梯 | 现价 32、涨跌幅 16、表格数值 13、正文 13、标签 11、轴刻度 10 |
| 行高 | 表格 32（紧凑 36 舒适）；正文 1.6 |
| 数字对齐 | 价格右对齐、涨跌幅右对齐、成交量右对齐、名称左对齐 |

## 六、适用边界

- **卡片化在窄屏会反噬。** 宽度 <1024 时卡片边距降为 8、容器圆角降为 10，不通过缩放字号补偿。
- **糖果色的面积上限。** 涨跌浅底只用于 hover 行、选中行与胶囊，永不做整列底纹；同时出现 3 个以上糖果色块即视为失败。
- **奶油底在强光与小屏上对比不足。** 需保留“隐藏网格线”与“提高对比度”两个设置项。
- **空心阳线在极高密度（1 分钟线、长历史窗口）下视觉变轻**，盘面会显得偏空，需提供实心切换。
- **【待确认】低饱和红绿与“糖果感”的取舍。** 红涨绿跌是 A 股用户硬习惯，一旦把红降到粉、绿降到奶绿，涨跌辨识速度下降，与仿真训练目的冲突。建议：色相不动，只降填充档明度，靠形状承担可爱感——但这条与“要够可爱”的偏好直接冲突，记录冲突本身，不擅自裁决。
- **【待确认】红绿反转开关。** 面向美股、加密用户或色弱用户需要可切换，但切换后与“红涨绿跌”的中国用户预期矛盾，需产品决定是否开放。
- **【另一解】若希望整体更偏甜系**，可把主交互色换成蜜桃粉 `#E8846F`，但会与涨红同色相、稀释语义，需同时把涨色向洋红侧偏移并重新校验等明度约束。
- **【另一解】布局也可取“上图表、下盘口”的单列三段式**，权重规则不变，装饰配额更集中。

## 七、冲突记录

| 冲突 | 处理 |
|---|---|
| 可爱风格与金融工具的严肃观感 | 靠配额隔离（S4）：装饰只占瞬时与边缘场景，主工作区保持工具感 |
| 品牌色想用薄荷绿，但绿等于跌 | 品牌色改紫；绿色系整体让给语义层 |
| 吉祥物拟人化与风险提示的合规要求 | 吉祥物、插画不进入下单确认、风险提示、亏损结算页 |
| 大圆角与图表精度 | 画布零圆角（S2、L7），两者不互相贬低 |
