# UI__kline-simulator-visual-language

> 状态：已裁决，首版界面已实现。视觉装饰保持可爱繁复；文案采用简洁、直接的功能表述。来源为用户提供的原始资料 `human-source/UI-design.md`；其严肃、扁平、零装饰等方向已被用户推翻。
> 本文件不改变 [[FEATURE__kline-practice-simulator]] 的行为规格，只约束界面的视觉与交互。

## 适用范围

K 线模拟器的前端界面（浅色模式）。不适用于后端接口和数据层。

## 风格方向（已裁决）

- 花里胡哨、动画多、装饰繁复、可爱。金融领域不是放弃可爱的理由。
- 装饰、圆润图形和动效可以用在界面各处，包括侧栏和浮层。
- 半透明毛玻璃、柔和渐变、细节装饰均可使用。
- 不做“减少动画”开关。
- 鼠标指针样式也要可爱。
- 字体可爱：中文界面文字和标题使用圆润字体；文案直接、简洁，不用广告口号、拟人化表达或情绪化旁白。
- 不放吉祥物、插画人物。
- 未来可以加入 2D 看板娘（眼睛跟随鼠标）。这是后续想法，不在当前范围内。
- 原文“扁平”“零装饰”“零动效”“零吉祥物”的约束作废。

## 蜡烛图（已裁决）

- 要有质感，不接受粗黑、厚重、没有审美的样式。
- 具体手法：
  - 实体四角圆润（圆角加一点，不做大圆角）。
  - 柔和的细描边。
  - 淡色填充，加轻微高光。
  - 影线变细。
- 允许蜡烛图有装饰细节和动画（如涨跌时的微动效）。
- 阳线与阴线都是实体，不使用空心线，不提供实心/空心切换。

## 颜色与数据可读性（保留）

- 红涨绿跌，保留 A 股习惯。涨跌仅靠颜色区分，不做色弱辅助。
- 红绿反转开关不开放。
- 主交互色为浅紫色底，文字用暖黑 `#2C2723`。
- 关键信息文字与背景对比 ≥ 4.5:1；涨跌两色等明度（L\* 差 ≤ 5，C\* 差 ≤ 10）。
- 红色只表示涨。危险、错误、删除使用琥珀色 `#C98A2E` 加图标。
- 指标线使用冷色系 `#6C4EE3`、`#1D7FBF`、`#B04FC4`、`#3F4E68`、`#7F93B3`，线宽 3/2/2/2/1px，并以实线、点线、虚线、长虚线、稀疏点线区分。主图内的指标线不得使用红、橙、绿，以免被误读为涨跌。
- 成交量柱使用涨跌填充色 30% 透明度。
- 数字等宽在册，不用圆体，保证价格和成交量列对齐（用户已确认）。中文字体可用圆润风格；文案保持简洁、直接。

## 布局与首版实现

- **三栏铺满**：桌面端占满视口宽度，只保留 12–16px 外边距。左栏放标的设置、下单、自定义指数和账户设置；中间是 K 线主图；右栏放指标与周期、模拟账户和成交记录。
- **主图优先**：主图宽度吃掉左、右栏之外的剩余空间，高度约为 `100vh - 146px`；左右栏高度跟随视口并在内容超出时独立滚动，页面本身不产生纵向滚动。
- **标签位置**：成交量、MACD 标签放在右侧价格轴列，与价格刻度同一条竖线，不再覆盖蜡烛和指标线。
- **实时图例与悬停**：图例显示日期、开高低收、成交量、各条可见均线和 DIF/DEA/MACD 的当前值；鼠标悬停时跟随十字线更新，移出后回到最新一根。悬停同时显示跟随指针的 OHLC 小卡片。
- **小屏**：宽度 ≤ 1100px 时改为两栏，右栏移到主图下方；≤ 900px 时主图在上、控制卡片在下，不压缩主图。
- **侧栏顺序**：标的选择与随机抽取、成交价模式与下单、创建自定义指数、账户设置与模拟费率。
- K 线画布面积 ≥ 视口 55%。
- 中文使用圆润无衬线字体；数字使用等宽字体。字体从前端依赖本地打包，不请求外部字体服务。
- 鼠标指针使用浅紫星芒造型。
- 当前 lightweight-charts 首版采用柔和红涨绿跌、细描边和纤细影线；图表库原生蜡烛矩形暂不支持圆角实体和单独高光，后续可用自定义绘制增强。
- 顶栏和下单按钮旁常驻“模拟盘”胶囊，不少于 56×20，不可隐藏。
- 不做网格线，不做高对比度设置。
