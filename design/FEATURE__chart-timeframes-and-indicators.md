# FEATURE__chart-timeframes-and-indicators

> 状态：已确认并完成实现（2026-11-09）。

## 验证

- `npm run check:chart` 校验周/月聚合、SMA、MACD 计算、参数约束，以及推进/切换周期时的可视区间保持。
- `npm run build` 通过；界面可在日/周/月间切换并显示均线、成交量和 MACD。
- 浏览器检查：三栏布局无横向滚动，成交量/MACD 标签位于右侧价格轴列；三组 MACD 预设可切换并更新数字框，控制台无错误。
- 图表交互本身未做浏览器自动化测试，仍需人工复核。

## 目标与范围

在模拟器 K 线图中查看日线、周线、月线，并同步显示均线、成交量和 MACD。所有指标只使用当前模拟日期及以前的数据。

## 规则

- **周期**：日、周、月。周/月线由 Baostock 日线本地聚合，不请求新数据源。
- **周/月聚合**：开盘为周期首个交易日开盘，最高/最低为周期内最高/最低，收盘为最后一个已发生交易日收盘，成交量/成交额求和。当前未结束周期显示截至模拟日期的部分 K 线。
- **推进与撮合**：模拟引擎仍逐个交易日推进；切换周期只改变图表聚合，不改变订单撮合粒度。订单仍使用下一交易日的日线 OHLC 和已选价格模式，避免用周/月合成 OHLC 撮合。
- **缩放**：推进后保持横向缩放（每屏 bar 数）不变。若图表原先跟随最新 K 线，则随新数据向右平移一根；若用户已滚动离开最新端，则保持原视窗，不强行跟随。首次加载显示最近约 80 根；只有用户主动切回或重新开始模拟时才重置视窗。
- **上下文历史**：后端状态至少提供最近 2000 根日线（截至模拟当前日），以支持 60 期月线均线计算；返回值仍不得含未来数据。
- **均线**：简单移动平均（SMA），K 线和每条均线都可独立开关，周期可调整。用户指定日线默认周期为 5、22、61、122、244 个交易日。
- 周线对应默认周期为 1、4、13、26、52 根周 K；月线对应 1、3、6、12 根月 K（5 日均线短于一个月，不显示为月线默认值）。均线只使用所选图表周期的收盘价计算。
- **成交量**：与 K 线共享时间轴的独立下方面板，不与价格轴共用刻度。
- **MACD**：依据 `human-source/UI-design.md` 之外，按用户本轮提供的《MACD 的有效性与参数选择》推导：对数收盘价 `p=ln(close)` 计算 EMA，`alpha=2/(N+1)`；`DIF=EMA(f)-EMA(s)`，`DEA=EMA(DIF,g)`，柱体 `H=DIF-DEA`。约束 `f<s` 且 `g>1`。
- **MACD 参数**：提供三个预设，选择后填入下方三个可编辑数字框：
  - 默认 `(10,22,8)`，初始选中；
  - 理论较优 `(5,10,9)`，来自 [[RESEARCH__macd-theoretical-optimum]] 的三维 Pareto 膝点，只代表模型内结果；
  - 经典 `(12,26,9)`。
  手动修改任一数字后不再高亮预设。所有周期（日/周/月）共用同一组参数。
- 参数搜索的实际结果见 [[RESEARCH__macd-parameter-search]]：本样本上没有通过多重检验的更优参数；MACD 主要表现为降低暴露和回撤，未显示稳定超额。三组预设都只是候选起点，不是实证最优。
- **标签**：成交量、MACD 标签放在右侧价格轴列，与价格刻度对齐，不覆盖绘图区。
- MACD 与均线都只依据已显示的周期收盘值计算；部分周/月 K 线随日线推进而更新。

## 不包含

- 本步不自动进行参数网格搜索、walk-forward、Deflated Sharpe 或 Reality Check；文章指出这些检验需要具体样本和成本假设，不能据公式直接宣称最优。
- 不做分钟线或盘中 MACD。

## 已确认的显示与模拟语义

- 周/月线只改变显示聚合，模拟仍逐交易日推进；周/月线当前柱为截至模拟日期的部分柱。
- 订单按下一交易日的日线 OHLC 撮合，不使用合成周/月 OHLC 伪造成交。
- 图表布局：K 线和均线位于主图，可分别开关；成交量和 MACD 各在独立下方面板，与主图共享时间轴。
- MACD参数可调，若输入非法或 `f>=s`、`g<=1`，拒绝保存。
