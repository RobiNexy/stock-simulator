# FEATURE__chart-timeframes-and-indicators

> 状态：已确认并完成实现（2026-11-09）。

## 验证

- `npm run check:chart` 校验周/月 W-FRI 与自然月分组、标签取最后交易日、`n_days`/`virtualDays`、provisional、停牌虚拟 K 的单日/多日插值、SMA、SMA 种子 EMA、MACD 柱体倍数，以及推进/切换周期时的可视区间保持。
- `npm run build` 通过；界面可在日/周/月间切换并显示均线、成交量和 MACD。
- 用同一份 2000 根日线和相同的停牌插值规则分别跑前端实现与规格中的 Python 实现：周/月 MA(4/13/26/52、3/6/12/24) 与 MACD(12,26,9, close/SMA/hist×2) 在最后两根上逐位一致（保留 8 位小数）。
- 浏览器检查：三栏布局无横向滚动，成交量/MACD 标签位于右侧价格轴列；三组 MACD 预设可切换并更新数字框；周/月默认经典参数并显示“未完成周K/月K”；悬停 K 线时图例和 OHLC 卡片更新，控制台无错误。
- 图表交互本身未做浏览器自动化测试，仍需人工复核。

## 目标与范围

在模拟器 K 线图中查看日线、周线、月线，并同步显示均线、成交量和 MACD。所有指标只使用当前模拟日期及以前的数据。

## 规则

- **周期**：日、周、月。周/月线由 Baostock 日线本地聚合，不请求新数据源。
- **周线分组**：按交易日归入“周五结束”周期（等价 `W-FRI`），周期标签取该组最后一个交易日；节假日周可能只有 1–4 个交易日。月线按自然月分组，标签同样取该月最后一个交易日。
- **周/月聚合**：开盘为周期首个交易日开盘，最高/最低为周期内最高/最低，收盘为周期最后一个交易日收盘，成交量/成交额求和；记录 `n_days`（周期内真实交易日数，不含虚拟停牌日）和 `virtualDays`（周期内虚拟停牌日数）。周期内全部停牌时仍生成一根虚拟周期 K，标记为 virtual。
- **停牌虚拟 K**：日线中 `volume<=0` 的停牌日替换为虚拟 K 线。单日停牌取前后两根真实 K 线的 OHLC 均值；连续多日按前后真实 K 线的 OHLC 逐字段线性插值（第 i 根权重为 `i/(n+1)`），成交量/成交额保持 0。区间缺少前文或后文时，用仅存一侧的真实价格填充。虚拟日参与 MA/MACD 计算，使序列等距。
- **推进与撮合**：模拟引擎仍逐个交易日推进；切换周期只改变图表聚合，不改变订单撮合粒度。订单仍使用下一交易日的日线 OHLC 和已选价格模式，避免用周/月合成 OHLC 撮合。
- **缩放**：推进后保持横向缩放（每屏 bar 数）不变。若图表原先跟随最新 K 线，则随新数据向右平移一根；若用户已滚动离开最新端，则保持原视窗，不强行跟随。首次加载显示最近约 80 根；只有用户主动切回或重新开始模拟时才重置视窗。
- **上下文历史**：后端状态至少提供最近 2000 根日线（截至模拟当前日），足以覆盖 52 根周 K 与 24 根月 K；返回值仍不得含未来数据。
- **均线**：简单移动平均（SMA），K 线和每条均线都可独立开关，周期可调整。参数单位是“当前周期 K 线根数”，不是日历时长；`N=1` 不纳入。
  - 日线默认 5、21、61、122、244 个交易日（“一月”取 21 已由用户裁决）；
  - 周线默认 4、13、26、52 根周 K；
  - 月线默认 3、6、12、24 根月 K。
- **成交量**：与 K 线共享时间轴的独立下方面板，不与价格轴共用刻度。
- **MACD 定义**：`alpha=2/(N+1)`，`DIF=EMA(f)-EMA(s)`，`DEA=EMA(DIF,g)`，`HIST=hist_mult*(DIF-DEA)`。
  - 日线保持已实现口径：`log(close)`、`first` 种子、`hist_mult=1`、默认 `(10,22,8)`；
  - 周/月线按新规格：`close`、`sma` 种子、`hist_mult=2`、默认 `(12,26,9)`。周线明确采用时间语义，不启用衰减匹配。EMA 在有效窗口前输出空值，不绘制预热期。
- **MACD 参数**：提供三个预设，选择后填入下方三个可编辑数字框：
  - 默认 `(10,22,8)`（日线初始选中）；
  - 理论较优 `(5,10,9)`，来自 [[RESEARCH__macd-theoretical-optimum]] 的三维 Pareto 膝点，只代表模型内结果；
  - 经典 `(12,26,9)`（周/月线初始选中）。
  手动修改任一数字后不再高亮预设。日/周/月各自保存当前参数，切换周期时恢复该周期的选择。
- 参数搜索的实际结果见 [[RESEARCH__macd-parameter-search]]：本样本上没有通过多重检验的更优参数；MACD 主要表现为降低暴露和回撤，未显示稳定超额。三组预设都只是候选起点，不是实证最优。
- **未完成周期**：最后一根周/月 K 若尚未到周期末，标记为 provisional：图例显示“未完成周K/月K”，蜡烛使用更浅的填充，数值仍随模拟日更新；该柱不用于回测。
- **虚拟 K 样式**：虚拟停牌日及全虚拟周期使用浅紫色蜡烛，图例/悬停显示“虚拟停牌K”或“含 N 个虚拟日”。
- **预热**：周/月 MACD 以慢线 `ceil(ln100/alpha)` 根作为预热长度；图例和悬停提示显示“MACD 预热期”，数据不足时显示“数据不足预热”。预热值仅展示，不用于产生交易信号。
- **时间对齐**：周期指标在 `label`（最后一个交易日）收盘后才完整可知；交易决策只能使用下一交易日及以后的值。图表仅展示，不把未完成周期值当作已完成历史。
- **标签**：成交量、MACD 标签放在右侧价格轴列，与价格刻度对齐，不覆盖绘图区。
- **图例与悬停**：图例实时显示当前（或悬停）K 线的日期、开高低收、成交量、`n_days`、可见均线值和 DIF/DEA/MACD；悬停时跟随十字线，移出后回到最新一根。悬停另显示跟随指针的 OHLC 卡片。均线颜色、线宽与线型对应 `design/UI__kline-simulator-visual-language.md`。

## 不包含

- 本步不自动进行参数网格搜索、walk-forward、Deflated Sharpe 或 Reality Check；文章指出这些检验需要具体样本和成本假设，不能据公式直接宣称最优。
- 不做分钟线或盘中 MACD。

## 已确认的显示与模拟语义

- 周/月线只改变显示聚合，模拟仍逐交易日推进；周/月线当前柱为截至模拟日期的部分柱，并标记 provisional。
- 订单按下一交易日的日线 OHLC 撮合，不使用合成周/月 OHLC 伪造成交。
- 图表布局：K 线和均线位于主图，可分别开关；成交量和 MACD 各在独立下方面板，与主图共享时间轴。
- MACD参数可调，若输入非法或 `f>=s`、`g<=1`，拒绝保存。
