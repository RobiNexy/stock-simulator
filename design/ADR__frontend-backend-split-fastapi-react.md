## 背景与决策

模拟器和回测需要数据处理、计算和界面展示。决定采用前后端分离：

- 后端：Python + FastAPI，位于 `backend/`，使用 uv 管理依赖。
- 前端：TypeScript（严格模式）+ React，位于 `frontend/`，使用 Vite 构建。
- 根目录提供一键启动脚本，同时启动前后端。

## 理由

- 数据获取与回测集中在 Python 生态，FastAPI 便于直接复用。
- 前端 TypeScript 严格模式减少界面层的类型错误。
- 分离后两端可独立测试和替换。

## 后果

- 收益与代价：需要维护两套依赖和两个开发服务；通过根目录脚本降低启动成本。
- 前端通过 Vite 代理访问 `/api`，避免开发阶段跨域问题。
- 启动脚本目前仅支持 Linux/macOS（bash）。

## 重新评估条件（可选）

- 单人开发中两端维护成本明显超过收益。
- 需要 Windows 原生支持且脚本成本过高。
