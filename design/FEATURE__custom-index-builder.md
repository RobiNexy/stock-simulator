# FEATURE__custom-index-builder

> 状态：已确认并完成首版实现（2026-11-06）。核心计算、持久化和 API 有单元测试；另用临时目录验证了 Baostock 两只真实成分股建指数并完成一次模拟成交。

## 目标与行为

Baostock 缺少科创 50 等指数数据，用户可手动定义成分股，由本地日线计算指数走势。自定义指数可用于本地模拟交易和研究对照，但不是交易所指数或真实可交易证券。

- 给定 指数名称、成分代码和权重模式，当 创建指数，则 校验所有代码并持久化定义；输入支持手动输入或粘贴，本步不做 CSV 导入。
- 给定 权重模式为等权或手动权重，当 创建指数，则 保存归一化权重，手动权重必须为正数且总和大于零。
- 给定 用户未指定基日，当 创建指数，则 自动取所有成分都有行情的最早共同交易日作为基日，基点为 1000。
- 给定 有完整成分日线，当 查询指数日线，则 返回按权重计算的 OHLC、成交量和成交额，并标注“自定义指数，非官方口径”。
- 给定 某成分股停牌，当 计算指数，则 OHLC 以该成分最近有效收盘价持平，成交量和成交额记 0；不将缺失行情当成零价格。
- 给定 成分股无效或没有共同基日，当 创建指数，则 拒绝创建并指出问题代码，不保存部分定义。
- 给定 自定义指数已保存，当 重启后端，则 定义和账户状态仍存在；计算结果可从成分日线重新生成。
- 给定 自定义指数作为模拟标的，当 买卖，则 以整数“份”为单位，在纯本地模拟账户内撮合并遵守 T+1；不接真实交易 API。
- 给定 自定义指数用于对照，当 查看模拟图表，则 可选择叠加该指数序列，不可对对照序列下单。

## 计算规则

- 基日自动取所有成分都有行情的最早共同交易日；基点 1000。
- 权重支持等权和手动配置，存储时归一化为和为 1。
- 使用前复权日线（见 [[FEATURE__daily-bars-from-baostock]]）。
- 每个成分的日价格相对值为 `成分当日价格 / 成分基日价格`；指数 O/H/L/C 分别为 `1000 × Σ(归一化权重 × 成分相应价格相对值)`。
- OHLC 聚合属于近似值，不等于官方指数的盘中高低点。
- 基日后停牌时，使用该成分最近一次有效收盘价作为当日 O/H/L/C，成交量和成交额为 0。基日要求所有成分均有行情。
- 成交量、成交额为当日成分之和；需注明这是简化合成指标，不代表指数真实成交量。
- 成分固定，不做市值加权、定期调仓或官方指数成分同步。

## 模拟交易语义

- 自定义指数是不可实盘交易的合成模拟标的。账户按整数“份”交易，不用股票 100 股整手限制；遵循 T+1。
- 买卖使用模拟器配置的佣金、印花税；指数是合成资产，不收沪市过户费。
- 交易价格按模拟器配置的下一根日 K 成交模式决定；随机模式使用并持久化随机种子。
- 所有交易、资产和盈亏都只存在本地模拟账户，不构成投资建议。

## 持久化与 API

- 定义存放于 `backend/data/indices/`，JSON 格式；计算结果可按需缓存，不缓存也可从成分日线重算。
- 提供创建、列表、详情和日线查询接口。
- 实现位置：`backend/app/data/custom_indices.py`、`backend/app/api/indices.py`。
- 检查：`uv run pytest -q` 覆盖权重、基日、OHLC、缺行情处理、持久化和 API 契约；临时目录中的 Baostock 真实数据 e2e 成功（两成分股、2024 区间 7 根、模拟买入成交）。
