# RESEARCH__macd-parameter-search

> 状态：第二版完成（2026-11-09）。第一版结果已被本版取代；第一版的买入持有基准取错样本区间，比较作废，更正见下文。
> 结论：在本次样本上，MACD 没有统计显著的超额收益，参数也不能被稳定识别；它更像降低暴露和回撤的择时开关，而不是稳定 alpha 来源。

## 一、对上一版的更正

上一版有一处会改变结论的错误：

- **买入持有基准取的是全样本（2002–2026），而策略是滚动前推的样本外（2007–2026）**，两者区间不一致。上一版表里的股票买入持有夏普 0.51、上证指数 0.29、沪深 300 0.27 都按全样本或不同区间计算，与策略不可比。
- 第二版把基准限制在与策略完全相同的样本外日期上，并改用同一执行口径（次日开盘到次日开盘）。
- 上一版"19 折中 13 折为正，p≈0.08"正确（精确值 0.0835）；"30 折中 18 折为正，p≈0.10"不准确，精确单侧二项概率为 0.181。

因此本文件只保留第二版结果。第一版代码和 JSON 仍可作为历史记录，但不再作为结论依据。

## 二、第二版方法

- **数据**：Baostock 日线，股票使用后复权（`adjustflag=1`），指数不复权。数据末日由实际返回决定并写入元数据：本次为 2026-11-06。
- **信号**：`p=ln(close)`，`DIF=EMA(f)-EMA(s)`，`DEA=EMA(DIF,g)`，`x_t=1{DIF_t>DEA_t}`。
- **成交**：收盘得到信号，次日开盘成交，收益从次日开盘计到再下一日开盘。这消除了"收盘信号按收盘价成交"的近似；T+1 由"每天最多一次决策"自然满足。
- **涨跌停**：买入时若次日开盘相对前收达到涨停（主板 10%，创业板/科创板 20%），不成交并保持原仓位；卖出遇跌停同理。指数不做限制。被阻断的笔数记录在每一折中。
- **成本**：单边 `5×10⁻⁴`。另做 0 与 `10⁻³` 的敏感性。
- **网格**：
  - 线性：快线 `8..14`、慢线 `18..30`、信号线 `5..12`，共 728 组；
  - 半衰期：`h∈{2,3,4,6,8,11,16,22,32,45,64}`，`alpha=1-0.5^(1/h)`，约束快线半衰期小于慢线，共 605 组。半衰期网格用来避免线性周期对长周期欠采样。
- **滚动前推**：训练 1250 个交易日，测试 250 个，步长 250；每折按训练净夏普选参数，只在随后测试段计收益。
- **风险指标**：年化收益、最大回撤、市场暴露比例、年化换手（单边仓位变化之和/年）。
- **显著性**：
  - Deflated Sharpe Ratio，作用在滚动前推拼接的样本外日收益上，试验次数取网格组数；
  - 配对分块 bootstrap（块长 60，5000 次），检验策略与买入持有的夏普差；
  - 随机择时基线：在每个测试窗口内随机平移仓位序列（保持相同暴露），2000 次，比较策略夏普。
- **样本**：5 只股票等权（`600000`、`000001`、`600519`、`000858`、`600036`）、上证指数、沪深 300。

半衰期网格的换手明显更低（5.9–13.1 次/年，线性网格为 18–21 次/年），但夏普没有改善，显著性也没有提高。网格内最佳固定参数仍偏向慢端：股票为 `32,64,32`（半衰期），上证为 `45,64,45`，沪深 300 为 `2,32,32`。

## 五、判读

1. **没有可辨识的超额收益。** 所有配对 bootstrap 区间都包含 0；随机择时 p 值均大于 0.05；DSR 均低于 0.95；折级正收益比例的单侧检验也不显著。结论与第一版在方向上一致，但第二版的比较是区间对齐的。
2. **MACD 的主要作用是降低暴露和回撤。** 暴露约 47%–51%，股票和上证的最大回撤比买入持有低 20 个百分点以上，代价是年化收益下降或持平。这支持"择时降低风险"的说法，不支持"提高夏普"的说法。
3. **参数位于慢端边界。** 线性网格快线取到上限 14，慢线接近上限；半衰期网格慢线半衰期取到上限 64。扩大网格不能回答"是否还应该更慢"；需要把参数空间继续向慢端扩展，或改用信噪比估计，而不是继续在整数网格上加宽。
4. **参数选择不稳定。** 上证 30 折中最高频参数只出现 3 次；沪深 300 的 16 折几乎没有重复。折间选择差异大，说明样本内的峰值不可迁移。
5. **成本。** 股票样本的滚动前推夏普在 0、5bp、10bp 单边成本下为 0.384、0.352、0.277，每增加 5bp 约衰减 0.03–0.08；半衰期参数换手低，对成本更不敏感。所有结果都按 5bp 报告。
6. **构造性校验。** 半衰期网格的最佳固定参数换手只有 1.4–8.7 次/年，夏普反而高于快参数，说明高频交叉在这一样本里主要是成本负担。

## 六、对评审要点的处理

- **复权**：已统一为后复权并在 `config.adjusted` 记录。后复权与前复权只差一个常数比例，日对数收益不变；本次仍按评审要求改用后复权并记录。
- **执行时点**：已改为次日开盘成交，收益为开盘到开盘；T+1 由决策频率保证；涨跌停按主板 10%、创业板/科创板 20% 阻断。
- **DSR 口径**：作用在滚动前推拼接的样本外收益上，试验次数取网格组数。另报告"网格最佳固定参数"的事后 DSR，并标注其为事后选择，存在偏差。
- **夏普口径**：无风险利率取 0，按日对数收益等权拼接；空仓收益按 0 计。这会低估高利率时期的现金收益，但样本大部分时间利率较低，影响有限。
- **样本终点**：实际数据末日 2026-11-06；可决策日最后为 2026-11-04，因为还需要 `t+1` 开盘和 `t+2` 开盘才能形成一笔收益。
- **幸存者偏差**：股票池是事后选定的存续大市值公司，买入持有被抬高，因此"股票池策略跑输买入持有"的结论对 MACD 偏保守；指数样本没有该偏差，结论以指数样本为主。
- **未来函数测试**：`tests/test_macd_search_v2.py` 断言截断价格序列后，截断点之前的 `EMA`、`DIF`、`DEA` 完全不变。

## 七、仍然不能回答的问题

- 是否有更慢的参数、或非线性/状态空间形式的趋势指标更合适；本实验只覆盖 MACD 的 EMA 参数。
- 收盘竞价能否按收盘价足额成交；本实验已改用次日开盘，但仍假设开盘价可成交，未模拟冲击成本。
- 现金收益、融券成本、股息再投资的税费。
- 历史成分股（point-in-time）与更广的股票池；当前股票样本存在幸存者偏差。
- 跨市场、跨制度阶段的稳健性；结论只适用于本次样本。

## 九、理论对照

按 [[RESEARCH__macd-theoretical-optimum]] 的两态链模型（`D=20`、`ρ=0.05`）：

- 趋势判据的平台在短窗口一侧（`f≈3–6`、`s≈8–15`），三维 Pareto 膝点为 `(5,10,9)`，原文建议的 `(5,12,9)` 与它几乎等价；
- 把 `D` 提高到 40–60 时，膝点的慢线移到 `s≈20–26`，方向与本文实证的慢端一致；但快线仍在 5–6，无法解释实证的 `f=14`（且 `f=14` 是线性网格边界）；
- `ρ` 只改变误差水平，不改变膝点位置。

因此理论与实证不能互相证实：实证目标是净夏普并含成本，理论是分类误差；`D` 与 `ρ` 也未从真实数据估计。可以保留的结论是：模型内的平台候选为 `(5,10,9)`，但不应据此改实盘或宣称任何参数最优。

界面因此只把它作为三个可切换预设之一：默认 `(10,22,8)`、理论较优 `(5,10,9)`、经典 `(12,26,9)`。三者都只是候选起点，参数仍可手动修改；默认值没有改成理论值。
